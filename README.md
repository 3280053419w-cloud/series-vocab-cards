# 剧集记忆卡 · Series Vocab Cards

**看剧学英语的循环记忆工具** —— 把一集剧里的地道表达提取成卡片，用 Anki 式四档评级反复推给你，直到记住为止。

👉 **在线使用**：https://3280053419w-cloud.github.io/series-vocab-cards/

---

## 它解决什么问题

看美剧最大的浪费是：**情节记住了，表达一个没留下**。

这个工具把一集剧里的短语动词、习语、俚语挑出来（一集 50 条），做成卡片：
正面看英文原句 → 显示答案 → 背面是中文译句 + 词条 + 音标。

```
正面：  So, you're living your life free and easy, and then one day,
        at a time of their choosing bam! They bring the hammer down to Chinatown.

背面：  你日子过得逍遥自在，然后某天，在他们挑好的时刻，砰！他们就朝唐人街下手了。
        （bring the hammer down on：对某人严惩；从重打击  /brɪŋ ðə ˈhæmər daʊn ɑːn/）
```

句子全部取自剧本原文，不是造的例句——记的是**真实语境**。

---

## 核心：不认识的反复推

四档评级，各档决定这张卡下次什么时候再来找你：

| 按钮 | 含义 | 间隔 |
|---|---|---|
| **重来** | 完全没记住 | **当轮立刻重推**，直到你认熟 |
| **困难** | 想了一会儿 | 稍短 |
| **良好** | 记住了 | 按难度因子往后推 |
| **简单** | 太熟了 | 推得更远 |

按「重来」的卡**不会等到明天**，它当轮就会重新出现——这是「反复推到你记住」的关键。

间隔走 Anki 那套简化的间隔重复算法：学习步 → 复习步，难度因子动态调整，上限 365 天。进度存在浏览器本地，关掉再开接着刷。

## 其他功能

- **语音朗读**：卡片右上角 🔊 或快捷键 `R`。自动朗读英文原句，翻面补读词条；可调语速（0.7×–1.3×）、可选是否连中文一起读。
  - ⚠️ 如果你的系统没装英文语音包，读英文会用中文音色硬读。装法：Windows 设置 → 时间和语言 → 语言和区域 → 添加「English (United States)」→ 语言选项 → 下载「语音」→ 重启浏览器。
- **牌组管理**：设置里可逐个删除牌组，删除是**软删除**——卡片和学习进度都保留，随时能恢复。
- **每日新卡上限**：默认 20 张，避免一次压太多。
- **深色 / 浅色 / 跟随系统**三档主题。
- **进度导出**：设置里可导出 JSON，换设备能带走。

## 怎么用

**在线**：直接打开上面的链接。手机上可以「添加到主屏幕」，用起来跟 App 一样。

**离线**：下载 `index.html`，双击就能用。**零外部依赖、不联网、不发任何请求**，所有代码和数据都在这一个文件里。

## 键盘快捷键

| 键 | 作用 |
|---|---|
| `空格` / `回车` | 显示答案 |
| `1` `2` `3` `4` | 重来 / 困难 / 良好 / 简单 |
| `R` | 朗读当前卡 |
| `Esc` | 返回牌组列表 |

## 技术说明

单文件 HTML（约 60 KB），原生 JavaScript，无框架、无构建依赖、无 CDN。
学习进度用 `localStorage` 保存；语音用浏览器内置的 Web Speech API。

在 Edge / Chrome / Safari 上均可运行（语音功能依赖系统语音包）。
