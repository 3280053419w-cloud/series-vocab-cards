# 剧集精读与精听 · Series Vocab

每天用 10 分钟学习 3—5 句剧集台词：读懂表达和语法，再隐藏字幕练听辨。原来的四档记忆卡复习继续保留。

## 开始使用

打开 `index.html` 即可使用，无需安装。也可以由 GitHub Pages 托管。进度保存在当前浏览器；在不同浏览器、设备，以及本地文件与在线网站之间不会自动同步。

1. 点击剧集，或点首页「继续逐句学习」。
2. **精读**：先看英文，尝试理解，再点「显示中文」。重点看「怎么用」和生活例句。
3. 不认识句中其他词时，展开「句中单词」；结构不明白时，展开「语法拆解」。
4. 展开「试着用一次」，完成填空，再写一句自己的生活例句。自己的句子会自动保存，不会自动批改。
5. 理解后点「这句读懂了」。点击「下一句」继续；每天不必学完整集。
6. **精听**：默认隐藏英文和中文，点「播放原句」。听不清时放慢或勾选循环，再点「显示英文」核对。
7. 恢复 1.0×、隐藏英文和中文，重听后再按实际表现点「无字幕听懂了」。系统朗读与剧集原声的听懂记录会注明来源。
8. 卡住时选择原因。之后从「听辨困难」筛选回来练；值得常用的表达可「收藏」。

听写为可选练习，核对忽略大小写和标点；红色下划线表示原句中漏写或需改的词，橙色表示听写中多写或需改的词。不同的合理改述不会被当作原句听写一致，核对结果不代表语言水平评分。

## 使用本机剧集原声

没有原声文件时，网页使用系统英文语音，并明确标注「系统合成朗读 · 非剧集原声」。系统需要可用的英文语音包；不同音色的联网要求取决于浏览器和系统。网页不自带演员原声，也不假设选出的句子构成连续场景。

1. 展开页面下方「用自己的剧集原声练习」。
2. 选择本机音频或视频，例如 MP3、M4A、MP4、WebM，具体支持取决于浏览器。
3. 选择**同一集、同一剪辑版本**的英文 SRT 或 VTT 字幕，建议 UTF-8 编码。
4. 唯一匹配成功时，播放器上方会显示「剧集原声 · 本机文件」和起止秒数。「播放原句」播放这段原声；语速和循环同样有效。
5. 无法唯一匹配时，网页会提示手动定位，并继续使用标明来源的系统朗读。可在下方播放器找到原句，填写开始和结束秒数，点「保存本句定位」。也可用「用当前位置作起点／终点」。

文件只在本机读取，不会上传。字幕匹配采取保守策略：重复台词、字幕版本不一致或不确定的匹配需要手动定位。浏览器支持的视频若只有不支持的音轨，仍可能无法正常发声。

重新打开网页需要重新选择原声文件。对于同名、同大小、同修改时间的文件，手动定位会保留；切换剧集会移除已选择的文件，避免误用其他集的原声。

## 复习、搜索和进度

- 「记忆复习」使用原来的四档卡片：重来、困难、良好、简单。「看用法」可直接回到当前句的精读。
- 搜索支持本集英文单词、短语、原句与中文；「目录」可以直接跳到某句。
- 精读、精听、收藏、自写例句、听写内容分别保存。标记听辨困难会取消这句的听懂状态。
- 「未到期」指记忆复习卡尚未到复习时间，不代表长期掌握。
- 每日新卡上限只影响「记忆复习」，不限制精读和精听。
- 在「设置」中导出 JSON 备份。换设备后从同一页面「导入」，确认后替换当前记录；建议恢复前先备份。
- 旧版本导出的进度文件仍可导入。原来的存储键和卡片 ID 保留，在线更新时同一浏览器的旧复习记录可继续使用。
- 「清空全部」会清空复习、精读、精听、收藏、笔记与手动原声定位，操作前有确认。

## 快捷键

精读／精听页面：左右方向键换句，`R` 播放，`Esc` 返回。输入框、下拉框、媒体控件与弹窗中不会抢占输入。

记忆复习页面：空格／回车显示答案，`1`—`4` 评级，`R` 系统朗读，`Esc` 返回。

## 内容与技术

现有《风骚律师》S04E05、S04E08 两集，共 100 条精选台词。每条包含语境释义、结构用法、生活例句与翻译、语法解释、语气或易错提醒、填空目标，以及适用的句中单词解释。

单文件 HTML、原生 JavaScript、无构建或 CDN 依赖。系统朗读使用 Web Speech API；本机音视频使用浏览器媒体播放器。短语讲解用于个人语言学习；台词和剧集名称版权属于原权利人。

开发校验：运行 `node tests/integrity.test.cjs`，检查全部教学条目、脚本语法、字幕匹配与进度备份格式。
